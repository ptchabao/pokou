Supprimer mon compte Pokou

Cette page permet de demander la suppression de votre compte Pokou sans passer par l'application. La suppression est définitive.

Vous pouvez aussi le faire depuis l'application : Plus → Confidentialité → Supprimer mon compte.

Ce qui est supprimé

  • Votre carnet d'adresses, vos statuts et les vues reçues.
  • Vos appartenances aux groupes et communautés : vous les quittez.
  • Vos votes de sondage, vos réactions, vos réglages de confidentialité.
  • Vos sessions et les notifications envoyées à vos téléphones.

Ce qui est rendu anonyme

Votre fiche de compte elle-même : numéro, nom, photo et code secret sont effacés, et le compte est désactivé. Votre numéro redevient libre : vous pourrez vous réinscrire, sur un compte neuf.

Ce qui est conservé

Les messages déjà reçus par vos correspondants : ils sont dans leur conversation, et les effacer effacerait aussi les leurs. Il en va de même du journal d'appels, partagé entre deux personnes. Les écritures comptables (paiements, factures) restent rattachées à la fiche rendue anonyme.

Demander la suppression

1. Votre numéro

Un code à 6 chiffres vous est envoyé par SMS, pour vérifier que ce numéro est bien le vôtre.

2. Le code reçu

3. Confirmation

Retapez votre numéro pour confirmer. Cette action est irréversible.

Une question ?

Écrivez à support@pokou.app en indiquant votre numéro. Nous répondons sous 30 jours.
